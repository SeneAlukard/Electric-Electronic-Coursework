## Getting started

```sh
git clone https://github.com/SeneAlukard/Electric-Electronic-Coursework.git
cd Electric-Electronic-Coursework
```

Run course-specific commands from the corresponding project directory. For the
Verilog workflow, start in `verilog/` and follow its [setup instructions](verilog/Readme.md).

## Repository consolidation

The third-year, fourth-year, and Verilog repositories were combined without
squashing or rewriting their original commits. Their files are now grouped by
source directory; documentation was updated for the combined layout.

Existing license files remain in their original project directories. This index
does not assign a new license to the combined coursework.
